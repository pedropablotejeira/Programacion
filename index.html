Sección 01

Pseudocódigo

¿Qué es?

Es una forma de describir un algoritmo usando un lenguaje similar al natural (español, inglés), combinado con estructuras propias de la programación, pero sin seguir la sintaxis estricta de ningún lenguaje de programación en particular. Esto quiere decir que podemos llevar o adaptar este tipo de código a muchos de los lenguajes de programación conocidos.

Es como un "borrador" o "boceto" de un programa: describe la lógica y los pasos a seguir, pero de forma legible para cualquier persona, no solo para una computadora.

¿Para qué sirve?

  • Planificar la solución de un problema antes de escribir código real.
  • Estructurado: usa palabras clave como Inicio, Fin, Si, Mientras, Para, Leer, Escribir.
  • Fácil de entender: cualquier persona con conocimientos básicos de lógica puede leerlo.
  • No es ejecutable: no puede correr directamente en una computadora, debe traducirse a un lenguaje real.
  • Flexible: no tiene una norma única, aunque sí convenciones comunes.
  • Enfocado en la lógica, no en detalles técnicos (como tipos de datos exactos o memoria).

Características

  • Independiente del lenguaje: no está atado a Python, Java, C++, etc.
  • Comunicar ideas entre programadores sin importar el lenguaje que usen.
  • Facilitar el aprendizaje de la lógica de programación sin preocuparse por errores de sintaxis.
  • Detectar errores lógicos antes de invertir tiempo escribiendo código.
  • Servir de puente entre el diagrama de flujo (representación gráfica) y el código fuente (representación en un lenguaje específico).

Sección 02

Diagramas de Flujo

¿Qué es?

Es una representación gráfica de un algoritmo o proceso, donde cada paso se representa mediante símbolos o figuras conectadas por flechas que indican el orden y la dirección en que deben ejecutarse las acciones.

Es una herramienta visual que permite "ver" la lógica de un programa o proceso antes de convertirlo en código.

¿Para qué sirve?

  • Visualizar de forma clara la secuencia de pasos de un algoritmo.
  • Detectar errores lógicos o pasos faltantes antes de programar.
  • Documentar procesos para que otras personas los entiendan fácilmente.
  • Facilitar la comunicación entre analistas, programadores y usuarios que no tienen conocimientos técnicos.
  • Servir de guía para traducir la lógica a cualquier lenguaje de programación.

Sección 03

Variables

¿Qué son?

Es un espacio en la memoria de la computadora que se utiliza para almacenar un valor, el cual puede cambiar durante la ejecución de un programa. Cada variable tiene un nombre (identificador) que permite referirse a ella y acceder o modificar el valor que contiene.

Se le llama "variable" precisamente porque su contenido puede variar (cambiar) a lo largo del programa, a diferencia de una constante, cuyo valor permanece fijo.

¿Para qué se utilizan?

  • Almacenar datos temporalmente mientras el programa se ejecuta (números, texto, resultados de operaciones, etc.).
  • Guardar valores ingresados por el usuario (por ejemplo, mediante Leer).
  • Almacenar resultados de cálculos u operaciones para usarlos más adelante.
  • Controlar el flujo del programa (por ejemplo, contadores en ciclos, condiciones).
  • Facilitar la reutilización de datos sin tener que escribirlos varias veces.

Características Clave:

  • Identificador: Nombre único y descriptivo (ej: edad).
  • Tipo de Dato: Define qué clase de valor guarda.
  • Ámbito (Scope): Determina en qué parte del código existe (local/global).

Sección 04

Constantes

¿Qué son?

Una constante es un espacio en la memoria que almacena un valor que no puede cambiar durante la ejecución del programa. Una vez que se le asigna un valor, este permanece fijo desde el inicio hasta el final del programa.

Al igual que las variables, tienen un nombre (identificador) que permite referirse a ellas, pero a diferencia de estas, su contenido es inmutable (no se puede cambiar).

Diferencia: Variable vs. Constante

Criterio Variable Constante
Valor Puede cambiar durante la ejecución Se fija una vez y no cambia (Inmutable)
Uso Típico Almacenar datos que varían (contadores, entradas del usuario, resultados) Almacenar valores fijos conocidos (π, ITBMS)

Ejemplos

Algoritmo Constante Const_PI = 3.1416; Definir radio como real; Definir area como real; Leer radio; area = PI * radio * radio; Escribir "El área del círculo es: ", area; FinAlgoritmo
Sección 05

Tipos de Datos

¿Qué son?

Los tipos de datos definen la clase de valor que puede almacenar una variable o constante, así como las operaciones que se pueden realizar con ella y la cantidad de memoria que ocupa. Son la clasificación básica de la información que maneja un programa.

Tipo Descripción Ejemplo
Entero Representa números sin decimales, ya sean positivos, negativos o cero. Se utiliza para contar, indexar o realizar operaciones matemáticas exactas. edad = 25
Real Representa números con parte decimal (punto flotante). Se usa cuando se necesita mayor precisión, como en cálculos matemáticos, científicos o financieros. estatura = 1.75
Carácter Representa un único símbolo: una letra, un dígito o un signo, encerrado normalmente entre comillas simples. Ocupa el menor espacio en memoria entre los tipos básicos. genero = 'M'
Cadena Representa una secuencia de caracteres (texto), es decir, palabras, frases u oraciones completas. Se encierra normalmente entre comillas dobles. "Hola Mundo"
Booleano Representa solo dos posibles valores: verdadero (true) o falso (false). Se utiliza principalmente en condiciones, comparaciones y control de flujo del programa. true / false

Sección 06

Entrada y Salida (I/O)

¿Qué es una entrada de datos?

La entrada de datos (Input) es el proceso mediante el cual un programa recibe información desde el exterior para poder procesarla. Esta información puede provenir de distintas fuentes: el teclado, un archivo, una base de datos, un sensor, otro programa, etc.

En pseudocódigo, la entrada se representa comúnmente con la palabra clave Leer, y en un diagrama de flujo con el símbolo de paralelogramo (▱).

Fuentes comunes de entrada:

  • Teclado (lo más común en ejercicios básicos)
  • Archivos (leer datos de un .txt, .csv, etc.)
  • Bases de datos
  • Sensores (en sistemas embebidos o IoT)
  • Otros programas o el mouse

¿Qué es una salida de datos?

La salida de datos (Output) es el proceso mediante el cual un programa muestra o envía información hacia el exterior, es decir, el resultado del procesamiento realizado.

En pseudocódigo, se representa comúnmente con la palabra clave Escribir o Mostrar, y en el diagrama de flujo con el mismo símbolo de paralelogramo (▱).

Destinos comunes de salida:

  • Pantalla (lo más común, mensajes en consola o interfaz gráfica)
  • Archivos (guardar resultados en un .txt, .csv, etc.)
  • Impresora
  • Bases de datos
  • Otros dispositivos (altavoces, actuadores, etc.)

Algoritmo Ejemplo I/O:

Algoritmo Entrada_Salida Definir nombre como cadena; Leer nombre; // ENTRADA Escribir "Hola, ", nombre; // SALIDA FinAlgoritmo
Sección 07

Estructuras Condicionales

¿Qué es una condición?

Una condición es una expresión lógica que se evalúa y da como resultado un valor verdadero (true) o falso (false). Se construye generalmente comparando valores mediante operadores relacionales (=, ≠, >, <, >=, <=) y, en ocasiones, combinando varias comparaciones con operadores lógicos (Y/AND, O/OR, NO/NOT).

¿Para qué se utilizan?

Las condiciones se utilizan para controlar el flujo de un programa, permitiendo que este tome decisiones y ejecute distintas acciones dependiendo de si una situación se cumple o no. Gracias a ellas, un programa deja de ser una simple secuencia de instrucciones y se vuelve capaz de reaccionar a diferentes escenarios (datos del usuario, resultados de cálculos, estados del sistema, etc.).

Se usan mediante estructuras llamadas estructuras de decisión o estructuras condicionales, cuya palabra clave principal es Si (If).

Condición simple

Evalúa una sola condición: si se cumple, se ejecuta un bloque de instrucciones; si no se cumple, simplemente no se hace nada (no hay alternativa).

Algoritmo Condicion_Simple Definir edad como entero; Leer edad; Si edad >= 18 Entonces Escribir "Eres mayor de edad"; FinSi FinAlgoritmo

Condición doble

Evalúa una condición y ofrece dos caminos posibles: uno si se cumple (Entonces) y otro si no se cumple (Sino).

Algoritmo Condicion_Doble Definir edad como entero; Leer edad; Si edad >= 18 Entonces Escribir "Eres mayor de edad"; Sino Escribir "Eres menor de edad"; FinSi FinAlgoritmo

Condición Anidada

Son condicionales dentro de otros condicionales, es decir, dentro del bloque Entonces o Sino de una condición se coloca otra estructura Si. Se utilizan cuando hay más de dos posibles resultados o cuando una decisión depende de otra.

Algoritmo Condicion_Anidada Definir nota como entero; Leer nota; Si nota >= 9 Entonces Escribir "Excelente"; Sino Si nota >= 7 Entonces Escribir "Bueno"; Sino Si nota >= 6 Entonces Escribir "Aprobado"; Sino Escribir "Reprobado"; FinSi FinSi FinSi FinAlgoritmo

Importancia en la toma de decisiones de un programa

  • Permiten que el programa "piense": en lugar de ejecutar siempre los mismos pasos, puede adaptar su comportamiento según los datos recibidos.
  • Hacen posible resolver problemas reales, que casi siempre implican distintos escenarios (validar una contraseña, clasificar edades, aprobar o rechazar una solicitud, etc.).
  • Son la base de estructuras más complejas, como los ciclos controlados por condición (Mientras) o la validación de datos de entrada.
  • Evitan errores en la ejecución, al permitir verificar antes de actuar (por ejemplo, comprobar que un número no sea cero antes de dividir).
  • Reflejan la lógica del mundo real dentro del programa: casi cualquier decisión humana ("si llueve, llevo paraguas; si no, no lo llevo") se puede traducir directamente a una estructura condicional.

En resumen, sin condicionales, los programas serían simples secuencias fijas de instrucciones, incapaces de adaptarse a distintas situaciones o datos.

Sección 08

Ciclos Repetitivos (Bucles)

¿Qué es un ciclo repetitivo?

Un ciclo repetitivo (también llamado bucle, iteración o estructura repetitiva) es una estructura de control que permite ejecutar un bloque de instrucciones varias veces, mientras se cumpla una condición o hasta alcanzar un número determinado de repeticiones.

¿Para qué se utilizan?

  • Evitar repetir código: en lugar de escribir 100 veces Escribir "Hola", se usa un ciclo.
  • Recorrer datos: por ejemplo, procesar todos los elementos de una lista o arreglo.
  • Validar entradas: pedir un dato hasta que el usuario lo ingrese correctamente.
  • Realizar cálculos acumulativos: sumas, promedios, factoriales, tablas de multiplicar.
  • Crear menús que se repiten hasta que el usuario decida salir.

Ciclo Para

Se usa cuando se sabe de antemano cuántas veces se repetirá el bloque. Utiliza una variable contador que va desde un valor inicial hasta un valor final, aumentando automáticamente en cada vuelta.

Algoritmo Ciclo_Para Definir i Como Entero; Para i <- 1 Hasta 5 Con Paso 1 Hacer Escribir i; FinPara FinAlgoritmo

Ciclo Mientras

Repite el bloque mientras la condición sea verdadera. La condición se evalúa antes de ejecutar el bloque, por lo que, si desde el inicio es falsa, el bloque no se ejecuta ninguna vez.

Algoritmo Ciclo_Mientras Definir i Como Entero; i <- 1; Mientras i <= 5 Hacer Escribir i; i <- i + 1; FinMientras FinAlgoritmo

Ciclo Repetir

Repite el bloque hasta que la condición sea verdadera. La condición se evalúa al final, por lo que el bloque se ejecuta al menos una vez.

Algoritmo Condicion_Repetir Definir clave Como Entero; Repetir Escribir "Ingresa la clave:"; Leer clave; Hasta Que clave = 1234; Escribir "Acceso concedido"; FinAlgoritmo
Sección 09

Relación entre los conceptos

Todos los temas que hemos estudiado no son piezas aisladas: se combinan entre sí para formar un programa completo.

Aprendimos cómo se construye un programa, que es la base para después poder analizarlos, protegerlos y encontrar sus fallas. Un programa sigue un flujo de cinco etapas:

  1. Entrada: Es el punto de partida, el programa recibe información desde afuera usando Leer. Esa información se guarda en variables, y cada una tiene un tipo de datos (entero, real, carácter, cadena o lógico) que define qué valores puede almacenar.
  2. Procesamiento: Una vez que los datos están guardados, el programa trabaja con ellos: hace cálculos, asigna valores con <- y transforma la información. Aquí las variables van cambiando de valor y se obtienen resultados intermedios.
  3. Condición: Aquí el programa toma decisiones con las estructuras Si / SiNo. Según el resultado de una condición (verdadero o falso), se ejecuta un camino u otro. Las condiciones pueden ser simples, dobles o anidadas, y sirven, por ejemplo, para validar datos o clasificar resultados.
  4. Repetición: Cuando una parte del programa debe ejecutarse varias veces, se usan los ciclos (Para, Mientras, Repetir). Los ciclos casi siempre se apoyan en condiciones para saber cuándo detenerse, y dentro de ellos también se pueden repetir entradas, procesos y decisiones.
  5. Salida: Al final, el programa muestra el resultado con Escribir: en pantalla, en un archivo, etc. Es lo que el usuario ve y lo que le da sentido a todo el proceso.
Sección 10

Conclusiones

Aprender pseudocódigo nos enseña a pensar como programadores y a resolver problemas lógicos, matemáticos y de diversa índole mediante procesos estructurados. Antes de escribir una sola línea de código, es fundamental analizar el problema, desglosarlo en pasos y ordenarlo de manera lógica; precisamente, esta capacidad de resolución es una de las habilidades más valoradas en la industria del software. Asimismo, dominar el uso de variables, condiciones y ciclos es clave para construir programas más eficientes, legibles y con menor margen de error.

La elaboración de cualquier programa se fundamenta en cinco etapas esenciales. Sin importar la complejidad del sistema —sea una simple calculadora, una aplicación bancaria, un videojuego o un protocolo de seguridad— el flujo principal es siempre el mismo: recibir datos, procesarlos, tomar decisiones, iterar tareas y entregar un resultado.

Hoy en día, campos de alta demanda como la inteligencia artificial, el desarrollo web, el análisis de datos y la ciberseguridad se erigen sobre estas bases. En ciberseguridad, por ejemplo, identificar una vulnerabilidad o proteger un sistema requiere entender primero cómo entra, se procesa y se despliega la información. Por ello, aunque estos conceptos parezcan elementales, representan el pilar fundamental para cualquier trayectoria en la programación.
